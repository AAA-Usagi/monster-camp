# 小怪营地 v1.1.0

把每天的工作变成一场轻冒险。Windows 本地桌面浮标，离线记录待办、识别中文时间、提醒、讨伐小怪与营地养成。

## 安装与使用

现有交付安装包位于 `../01_安装包/v1.1.0/MonsterCamp-Setup-1.1.0-x64.exe`，按照安装向导安装。已有旧版时先备份个人数据并从托盘退出。首次打开会显示清单和桌面小怪。默认随 Windows 登录启动，可在设置关闭。

此安装包为本地生成的未签名版本，未附带商业代码签名证书。

- 点击桌面边缘的小怪，输入一句话，回车保存。Shift + 回车可以换行。
- 输入“明天下午三点确认讲师”会预览识别出的日期和时刻，可修改或移除。只写“明天”安排到对应日期，不设具体时刻提醒。
- 未填写日期的任务放在“未定时间”；到期和逾期事项归入“今天”。搜索覆盖所有可见任务与历史记录。
- 点击任务文字可以编辑或删除。删除后有 10 秒可撤销。
- 新任务自动分配 12 种外形之一；编辑时保留外形。保留原 6 种，新增蘑菇、云团、水滴、岩石、火苗、小龙。
- 选择轻松／普通／挑战，对应小／中／大体型与 10／20／40 金币，默认轻松。完成时结算实际奖励，撤销时收回同样金额，重新完成按当前难度结算。已完成任务需先撤销才能调整难度。删除已完成记录保留金币和战绩。
- 金币达到 30 / 100 / 250 / 500，自动解锁帐篷、篝火、小屋、花园。已解锁的布置不会因为撤销完成而消失。
- 信箱保留到点提醒和每日回顾，支持延后 10 分钟、完成、标为已读。默认每日 09:00 回顾，可在设置调整。
- 收起面板继续运行。退出可用右下角托盘菜单；主动退出或关机期间不发提醒，下次打开时合并补查。
- 所有动画无声，可在设置关闭；系统“减少动态效果”偏好也会被尊重。

Windows 系统通知是否弹出取决于系统通知设置、专注模式及应用权限。通知被系统静音时，提醒仍保留在营地信箱，浮标显示未读提示。

## 数据与恢复

数据位于当前用户应用数据目录下的小怪营地文件夹，可在“设置 → 查看数据保存位置”查看准确路径。主文件为 `camp.json`，前一次有效记录为 `camp.backup.json`。

应用采用串行保存和临时文件替换，保存失败时保留输入。主记录损坏会提示恢复备份，原文件另存为 `camp.damaged-时间戳.json`。恢复备份可能丢失最近一次保存的修改。没有有效备份时不会自动创建空数据覆盖历史文件。

v1.1.0 使用数据格式 2。首次读取格式 1 时，先把原始主文件及已有备用文件保存到 `userData/backups/pre-v1.1.0-时间戳-随机后缀/`，逐项核对后再转换；失败时停止，原记录保留。这份迁移副本不会随日常自动备份轮换。旧任务按轻松档保留原有奖励、外形与营地解锁。回退至 v1.0.0 需要配套恢复旧格式数据，不能直接打开格式 2。

需要迁移到另一台电脑时，请先退出应用，复制整个数据文件夹，在另一台电脑安装应用并退出后，将文件放入其对应数据目录。卸载默认保留记录。

## 本地开发

当前源码根目录是 `02_项目源码`，下方命令均在本目录执行。后续打包输出为本目录的 `dist/`；验收后将安装包复制到交付根目录的 `01_安装包/v版本号/`，保留旧版。

非开发者请先阅读 `../03_使用与更新说明/使用与更新指南.txt`；接手维护请阅读同目录的 `维护交接说明.md`。原始验收记录中的构建路径保留其历史含义；交付截图在 `../04_界面预览/`。

需要 Node.js 24 或兼容版本。

```powershell
npm ci
node scripts/prepare-fonts.cjs
npm start
```

如果依赖安装后缺少 Electron 运行时，运行 `node node_modules/electron/install.js` 下载官方运行时。

```powershell
npm test
npm run test:desktop
npm run test:upgrade
npm run dist
```

`test:desktop` 使用 Playwright 驱动实际 Electron 窗口，数据存放在 `output/desktop-test-*`，不会设置开机启动，也不发送真实系统通知。截图位于 `output/playwright`。可用 `CAMP_EXECUTABLE` 环境变量指定已打包的可执行文件，验证发行版。

`test:upgrade` 用独立的 `output/upgrade-test-*` 数据验证格式迁移、三档奖励、连续点击、窄窗口及 12 种造型。开发和打包程序的结果分别写入 `output/upgrade-test-results-development.json`、`output/upgrade-test-results-packaged.json`，截图按版本和运行方式分目录。`CAMP_EXECUTABLE` 应指向 `dist/win-unpacked/MonsterCamp.exe`，不是 Setup 安装器。

应用运行不联网、不创建账号；Electron 主进程负责所有文件与系统操作，渲染页面通过白名单接口通信。字体和原始 SVG 插画随包提供。

## 验证范围

单元测试覆盖日期、奖励、提醒、浮标边界、并发持久化、磁盘故障和备份恢复。桌面自动化覆盖真实输入、编辑、搜索、删除撤销、完成撤销、营地解锁、提醒、设置及进程重启。

物理多屏拔插、真实电脑睡眠、Windows 登录后自动启动，以及系统通知弹出效果需在对应系统条件下人工验证；自动化分别验证它们的边界算法、补查逻辑和配置接口。

本次通过 38 项核心测试，以及开发和打包程序各 18 组桌面流程。真实安装向导和覆盖安装未在隔离系统中执行，详见 `docs/verification.md`。原版历史记录保留为 `docs/verification-v1.0.0.md`。
