# 小怪营地设计

Windows 本地工具，桌面浮标打开即记录；中文时间规则解析，四种视图归组，系统提醒与每日回顾。

视觉令牌：纸色 #fffaf0、草绿 #516e45、浅草 #e9edcf、暖橙 #d58743、墨绿 #34432e。字体为随包附带的 Noto Sans SC。以清晰的左对齐任务列表为主体，将软萌怪物与手绘营地作为唯一强视觉；避免把每行任务堆成独立仪表盘卡片。

面板：顶栏 / 今日战绩与金币 / 讨伐、营地页签 / 输入框和时间预览 / 分类与搜索 / 滚动任务列表 / 本地保存状态。输入始终优先，游戏无需额外配置。营地使用可逐阶段显现的 SVG 插画。

v1.1.0 保留六种原有小怪，新增蘑菇、云团、水滴、岩石、火苗、小龙。外形按任务 ID 自动分配并固定，难度独立控制体型和奖励。任务固定图像列宽为 72px（窄窗口 64px），三档图像尺寸为 40/54/68px（窄窗口 36/48/60px）。

轻松、普通、挑战分别奖励 10、20、40 金币，新建默认轻松。金币按已完成任务的实际 rewardEarned 求和，软删除不损失战绩；撤销完成扣回实际奖励并归零，再次完成按当前难度结算。已完成任务锁定难度。营地解锁单向累积，提示剩余金币。列表和信箱忽略连续点击的第二次事件，防止列表移动误伤相邻任务。

数据格式为 version 2，任务新增 difficulty 与 rewardEarned。先校验旧格式 1，再备份原始主文件和备用文件，核对一致后才原子迁移。迁移副本位于 userData/backups/pre-v1.1.0-时间戳-随机后缀，不参与日常备份轮换。旧任务映射为轻松，保留旧外形与奖励。任务更新和提醒收据由主进程串行、持久化后发布。数据损坏时显式恢复备份；不覆盖原损坏文件。

当前不含账号、云同步、联网 AI、商店、装备、Boss、子任务或重复任务。设置默认开机启动、每日 09:00 回顾、动画开启无声。开发与自动化测试使用独立数据目录，不更改真实开机启动配置。
